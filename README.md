This repository contains the Interview documentation and the full list of teamwork requirements extracted for the paper "A Taxonomy of Human-Robot Teamwork Requirements"

"Teamwork_Requirements.pdf" is a copy of the menuscript.
"TeamworkRequirementsRE - Sheet1.pdf" contains the requirements and classification for the construction corpus.
"ValidationCorpus.pdf contains" contains the requirements and classification for the validation corpus.
"Interview Protocol.pdf" contains details on the Interviews.
"ClassificationEvaluationMeetings.pdf" contains theslides and questions used for the interviews.
